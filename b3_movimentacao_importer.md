# B3 Importer Specification for Beancount

## Purpose

This importer converts data from B3 reports into Beancount transactions.

The importer consumes two independent data sources:

1. **Movimentações Report**

   * Income events
   * Corporate actions
   * Asset transfers
   * Fixed-income operations
   * Custody fees

2. **Negociações Report**

   * Exchange-traded purchases
   * Exchange-traded sales

The Negociações report is the authoritative source for buy and sell operations of stocks, FIIs, ETFs, BDRs, and other exchange-traded assets.

The Movimentações report should not be used to reconstruct exchange-traded trades.

---

# General Rules

## Idempotency

Every generated transaction must contain a deterministic identifier derived from the source record.

Example:

```beancount
id: "b3-20250515-000123"
```

Repeated imports must not generate duplicate transactions.

---

## Required Metadata

Every generated transaction must contain:

```beancount
id: "..."
source: "..."
asset: "..."
```

### Fields

#### id

Unique identifier generated from the source record.

#### source

One of:

```text
b3_movimentacoes
b3_negociacoes
```

#### asset

Ticker or synthetic ticker.

Examples:

```text
PETR4
MXRF11
TESOURO_SELIC_2029
CDB_BANCO_ABC_2028
```

#### warning

Optional metadata.

Examples:

```beancount
warning: "needs_review"
warning: "unmatched_transfer"
warning: "ticker_migration"
warning: "unknown_event_type"
```

---

## Cash Accounts

Cash movements should use the broker cash account associated with the event.

Examples:

```text
Assets:Broker:XP:Cash
Assets:Broker:BTG:Cash
Assets:Broker:Inter:Cash
```

---

## Equity Asset Naming

Exchange-traded assets:

```text
Assets:Investments:B3:<TICKER>
```

Examples:

```text
Assets:Investments:B3:PETR4
Assets:Investments:B3:MXRF11
Assets:Investments:B3:BOVA11
```

---

## Fixed Income Asset Naming

Some Movimentações events do not provide a ticker.

A synthetic ticker must be generated from the Product field.

Examples:

```text
TESOURO_SELIC_2029
TESOURO_IPCA_2035
CDB_BANCO_ABC_2028
CRI_COMPANHIA_XYZ_2030
```

Normalization rules:

1. Convert to uppercase
2. Remove accents
3. Replace spaces with "_"
4. Remove special characters
5. Ensure deterministic output

### Example

## Transferência - Liquidação

### Description

Settlement generated by a sale operation.

### Action

Ignore.

The corresponding sale must be imported from the Negociações report.

---

## Transferência

### Description

Asset transfer between brokers.

### Matching Rules

Transfers must be paired using:

* Same date
* Same asset
* Same quantity

Expected pattern:

```text
Broker A -> negative quantity
Broker B -> positive quantity
```

### Example

```beancount
YYYY-MM-DD * "Asset Transfer"

  id: "..."

  Assets:Broker:OldBroker:PETR4   -100 PETR4
  Assets:Broker:NewBroker:PETR4    100 PETR4
```

### Validation

Generate:

```beancount
warning: "unmatched_transfer"
```

when a pair cannot be found.

## Direitos de Subscrição - Exercido

### Description

Subscription rights exercised.

### Current Implementation

Receive shares at zero cost.

### Example

```beancount
YYYY-MM-DD * "Subscription Rights Exercised"

  id: "..."
  source: "b3_movimentacoes"
  asset: "ABCD3"
  warning: "needs_review"

  Assets:Investments:B3:ABCD3
      100 ABCD3 {0 BRL}

  Equity:CorporateActions
```

### Notes

This implementation intentionally prioritizes correct share quantities.

Subscription exercises usually involve a cash payment that is not currently reconstructed by the importer.

Manual review is required.

---

## Grupamento

### Description

Reverse split.

### Accounting Treatment

Importer must:

1. Read current quantity before the event.
2. Read the new quantity reported by B3.
3. Generate a synthetic sell of the old quantity.
4. Generate a synthetic buy of the new quantity.

### Example

Position before event:

```text
1000 XYZ3
```

Position after event:

```text
100 XYZ3
```

Generated transaction:

```beancount
YYYY-MM-DD * "Reverse Split"

  id: "..."
  source: "b3_movimentacoes"
  asset: "XYZ3"

  Assets:Investments:B3:XYZ3   -1000 XYZ3 {}
  Assets:Investments:B3:XYZ3     100 XYZ3 {}
```

The importer should preserve cost basis whenever possible.

Exact lot behavior depends on the chosen Beancount booking method.

# Warning Events

Warnings must never interrupt import execution.

Supported warnings:

```text
needs_review
unmatched_transfer
ticker_migration
unknown_event_type
```

Unknown movement types should generate:

```beancount
warning: "unknown_event_type"
```

and be skipped.

---

# Import Priority

Priority order:

1. Negociações report
2. Movimentações report
3. Manual entries

If information exists in both sources, the Negociações report is authoritative.
